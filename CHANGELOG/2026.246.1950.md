# 2026.246.1950 — fix: drop --locked from the himalaya cargo install

## Summary

`cargo install himalaya --locked` uses the himalaya crate's Cargo.lock, which
pins `chacha20 v0.10.1` — a crate yanked from crates.io. Every build composing
this candy (the openclaw-full metalayer among them) emitted the warning
`package chacha20 v0.10.1 in Cargo.lock is yanked in registry crates-io`.

Fix: drop `--locked` so cargo resolves the latest compatible transitive
versions, avoiding the yanked crate. The build remains reproducible at the
himalaya version level (cargo install pins the crate version from the command).
The candy's own CalVer moves because changed content must ship under a new
version.
